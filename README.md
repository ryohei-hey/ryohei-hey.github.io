# Academic website

Ryohei Yamamoto (Kobayashi) の研究者向け個人サイトです。Quartoで生成し、GitHub Pagesの `main/docs` から公開する構成です。

## ローカルで確認

```powershell
quarto preview
```

## HTMLを生成

```powershell
quarto render
```

生成先は `docs/` です。

## GitHub Pagesで公開

1. このフォルダを `ryohei-hey.github.io` という公開リポジトリにpushします。
2. GitHubの `Settings` → `Pages` を開きます。
3. Sourceを `Deploy from a branch` にします。
4. Branchを `main`、folderを `/docs` に設定して保存します。

プロフィール、研究内容、代表論文、CVは2026年9月の申請資料をもとに更新済みです。公開前には、日付依存の所属・役職・業績を再確認してください。
